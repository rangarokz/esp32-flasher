ESP32 Firmware Flasher

Connect your ESP32 board via USB to flash the controller firmware directly through your web browser.

Accelerator Controller

v1.0.0

Firmware for train accelerator and reverser throttle control with calibrated notch detents and direction inputs.

Web Serial is not supported in this browser. Please use Google Chrome or Microsoft Edge on Desktop.

Brake Controller

v1.0.0

Firmware for locomotive pneumatic brake handle control with calibrated multi-stage service detents and emergency state.

Web Serial is not supported in this browser. Please use Google Chrome or Microsoft Edge on Desktop.
Instructions
  • Connect the ESP32 using a data-capable USB cable.
  • If connection fails, press and hold the BOOT button on the ESP32 while clicking Connect.
  • Requires Google Chrome or Microsoft Edge on Desktop.
