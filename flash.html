Lazy Idli ESP32 Firmware Flasher

Connect your ESP32 board via USB to flash Lazy Idli Train Simulator controller firmwares directly through your web browser.

Accelerator Controller

v1.0.0

Firmware for Lazy Idli train accelerator and reverser control with calibrated notch detents and direction inputs.

Hardware Platform ESP32 (2MB+ Flash)
Throttle ADC Pin GPIO 34 (ADC1 CH6)
Reverser Pins GPIO 4 (Fwd), GPIO 16 (Rev)
Storage NVS Flash Memory
Web Serial is not supported in this browser. Please use Google Chrome or Microsoft Edge on Desktop.

Brake Controller

v1.0.0

Firmware for Lazy Idli locomotive pneumatic brake handle with calibrated multi-stage service detents and emergency state.

Hardware Platform ESP32 (2MB+ Flash)
Brake Lever ADC Pin GPIO 32 (ADC1 CH4)
Calibration Pin GPIO 0 (BOOT Button)
Status LED GPIO 2 (Onboard LED)
Web Serial is not supported in this browser. Please use Google Chrome or Microsoft Edge on Desktop.
Instructions
  • Connect the ESP32 using a data-capable USB cable.
  • If connection fails, press and hold the BOOT button on the ESP32 while clicking Connect.
  • Requires Google Chrome or Microsoft Edge on Desktop.
